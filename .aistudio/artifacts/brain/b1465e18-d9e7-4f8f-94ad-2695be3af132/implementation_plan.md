# 작업 진행상황 (Progress Bar) 모달 기능 구현 계획

사용자가 이미지를 **불러올 때**, **먼지 분석할 때**, **스팟 제거를 적용할 때**, 그리고 **파일을 내보낼 때** 나타나는 기존 중앙 모달 카드 내부에서 정확한 진행 단계 및 퍼센트 진행률(Progress Bar)을 시각적으로 표시하는 개선 계획입니다.

---

## 사용자 확인 및 주요 결정 사항

> [!NOTE]
> 사용자의 명확한 요구사항: "불러오는 중일 때 모달 카드 안에서 얼마나 진행되었는지(진행상황 및 퍼센트)를 표시하도록 추가"

- **표시 위치**: 이미지를 불러오거나 처리할 때 화면 중앙에 뜨는 작업 모달 카드 내부
- **표시 요소**: 
  - 단계별 진행 상태 메세지 (예: `파일 로딩 중...`, `메타데이터 및 파싱 중...`)
  - 실시간 퍼센트 수치 (예: `45%`)
  - 부드러운 애니메이션이 적용된 카키 포인트 컬러 (`#556042`) 프로그레스 바 게이지

---

## 1. 개요 및 핵심 기능

- **작업 모달 게이지 시각화**: `isProcessing` 모달 실행 시, 단순히 회전하는 스피너만 보여주는 대신 **실시간 진행률 게이지 바(0% ~ 100%)**와 **퍼센트 수치**를 제공합니다.
- **주요 4단계 작업 흐름과의 연동**:
  1. **이미지 불러오기 (Upload/Ingest)**: 파일 로딩 및 캔버스 초기화 진행률 (`0%` → `100%`)
  2. **먼지 분석 (Dust Detection)**: 이미지 축소판 생성 → 에지 탐지 → 스팟 클러스터링 (`0%` → `100%`)
  3. **적용 (Inpainting)**: 마스크 생성 → 이미지 인페인팅 처리 → 결과 렌더링 (`0%` → `100%`)
  4. **내보내기 (Exporting)**: RAW/TIFF/PNG/JPG 인코딩 및 메타데이터 주입 (`0%` → `100%`)

## 3. 기술적 구현 전략

### 시스템 흐름 및 데이터 처리 구조

```
┌────────────────────────┐      Worker Progress      ┌────────────────────────┐
│      App.tsx State     │ <------------------------ │     sensorWorker.ts    │
│  - isProcessing: true  │     postMessage({          │  - Read/Decode Buffer  │
│  - progressPercent     │        type: 'progress',   │  - Edge Detection      │
│  - processingLabel     │        progress: 0..100    │  - Inpaint Iterations  │
└────────────────────────┘     })                    └────────────────────────┘
            │
            ▼
┌────────────────────────┐
│   DarkroomCanvas.tsx   │
│  (Modal with Progress) │
└────────────────────────┘
```

1. **`sensorWorker.ts` 프로그레스 이벤트 전달**:
   - `ingest_and_detect`, `detect`, `inpaint`, `export_single` 비동기 루프 및 이미지 처리 과정에서 단계별로 `postMessage` 진행률(`progress`: 0~100) 보냄
2. **`localSensorEngine.ts` 진행률 콜백 추가**:
   - Worker로부터 들어오는 progress 이벤트를 받아 `onProgress(percent, label)` 콜백 호출
3. **`DarkroomCanvas.tsx` 모달 렌더링 수정**:
   - `progressPercent` prop을 전달받아 모달 카드 내부에 게이지 바와 % 수치 표시

## 4. 변경 예정 파일

- `src/services/localSensorEngine.ts`: Worker 진행률 콜백 핸들러 추가
- `src/workers/sensorWorker.ts`: 이미지 처리 단계별 프로그레스 이벤트 신호 추가
- `src/App.tsx`: `progressPercent` 상태 추가 및 로딩/분석/적용/내보내기 시 업데이트
- `src/components/DarkroomCanvas.tsx`: 모달에 게이지 바, % 수치, 단계별 보조 메시지 UI 추가

## 5. 검증 계획

- **기능 검증**:
  1. 이미지 업로드 시 모달에서 `0%` → `100%` 게이지가 부드럽게 상승하는지 확인
  2. "2. 먼지 분석" 버튼 클릭 시 분석 진행률 표시 확인
  3. "3. 적용" 버튼 클릭 시 스팟 제거 처리 진행률 표시 확인
  4. "4. 내보내기" 선택 시 인코딩 진행률 표시 확인
- **빌드 및 린터 검증**:
  - `lint_applet` 및 `compile_applet` 실행으로 오류 검증
