# SensorClean — Cloudflare Pages 전환 및 원본 색감·대비 100% 일치 계획

기존 앱의 모든 기능과 다크룸 UI를 그대로 유지하면서 **Cloudflare Pages(브라우저 로컬 연산)**용으로 전환하고, 내보낸 사진이 원본보다 흐릿하고 물 빠진 것처럼 보이던 **색감·대비(Tone Curve) 불일치 문제를 근본적으로 해결**합니다.

---

## 왜 내보낸 사진이 원본보다 흐리멍텅해 보였나요? (원인 분석)

첨부해 주신 두 사진을 비교해 보면, 하늘 밝기는 비슷하지만 **나무와 아스팔트 도로의 어두운 영역(블랙/섀도우)이 들떠 있고 전체 대비(Contrast)와 채도가 빠져 보이는 현상**이 확인됩니다. 원인은 다음 두 가지입니다.

1. **카메라 내장 S-커브(Tone Curve) 및 픽처 스타일 누락**
   - 갤러리 앱에서 원본 `.RW2` 파일을 볼 때는 파나소닉 카메라 엔진이 **강한 S-커브(깊은 블랙 + 섀도우 대비)와 카메라 컬러 프로파일**을 입혀 구워 둔 **내장 JPEG 프리뷰**가 표시됩니다.
   - 반면 기존 파이프라인은 센서 원본 데이터를 선형(Gamma 1.0)으로 현상한 뒤, 카메라의 S-커브 없이 **단순 수학적 표준 sRGB 감마(`x^(1/2.4)`)와 단일 밝기 배수(`exposure_scale`)**만 곱했습니다.
   - 그 결과 하늘(밝은 영역) 밝기에만 노출이 맞춰지면서 **암부(나무·도로)가 회색빛으로 들뜨고 안개 낀 것처럼 대비가 평평해지는(Flat) 현상**이 발생했습니다.
2. **복원 영역 외 픽셀의 재변환 손실**
   - 먼지가 없는 영역까지 16-bit 선형 변환 후 단순 감마로 재렌더링하면서 원본 고유의 계조 곡선이 희석되었습니다.

---

## 해결 방안: 원본 색감·대비 100% 매칭 엔진

> [!IMPORTANT]
> **카메라 내장 프리뷰 역추적 LUT 보정 + 비복원 영역 1:1 원본 보존**을 동시에 적용하여 원본과 구별할 수 없는 동일한 색감과 대비를 구현합니다.

1. **RAW 파일: 내장 JPEG 기반 65,536-엔트리 톤 커브·색감 역추적 LUT (Camera Look Matching)**
   - RAW(`.RW2`, `.DNG`, `.CR2`, `.NEF`, `.ARW` 등) 파일 내부에 들어 있는 **카메라 제조사 원본 JPEG 프리뷰(Embedded Preview)**의 채널별 히스토그램(CDF)과 암부/명부 S-커브, 채도 비율을 분석합니다.
   - 이를 바탕으로 16-bit 선형 센서 데이터(`0~65535`)를 카메라 원본 색감으로 정확히 매핑하는 **65,536-엔트리 정밀 톤 매핑 LUT**를 생성하여, 나무·도로의 깊은 블랙과 하늘의 색온도를 원본 그대로 재현합니다.
   - 만약 RAW 내부의 풀 해상도 내장 프리뷰/베이스 이미지를 사용할 때는 **먼지 마스크 바깥 영역(99% 이상의 깨끗한 픽셀)은 아예 건드리지 않고 원본 픽셀을 1:1 그대로 보존**합니다.
2. **일반 이미지 및 16-bit TIFF: 비복원 영역 100% 무손실 원본 유지 (Zero-Touch Outside Mask)**
   - 먼지 제거 마스크(`roi_alpha > 0`)가 적용된 미세 영역만 평면 디트렌딩 복원을 수행하고, 나머지 모든 픽셀은 원본 코드값을 **1비트도 바꾸지 않고 그대로 출력**합니다.
3. **DNG 1.4 내보내기 시 카메라 톤 커브 및 프리뷰 동기화**
   - 갤러리 앱이 읽는 `IFD0`(프리뷰)와 라이트룸이 읽는 `SubIFD0`(16-bit 데이터 + `ProfileToneCurve` / `ColorMatrix1`) 모두 보정된 카메라 톤 커브를 반영하여 어느 앱에서 열어도 흐릿해지지 않도록 만듭니다.

## 1. Cloudflare Pages 로컬 아키텍처 전환 요약

- **지금 있는 앱 그대로 Cloudflare Pages 정적 호스팅 호환**:
  - 기존 UI(단일/연속 촬영 모드, 드래그 지우개 브러시, 수동 복원 브러시, `Undo`/`Redo`, `복원 되돌리기`, 전/후 비교 뷰)를 100% 그대로 유지합니다.
  - 서버 API 호출(`/api/*`) 대신 브라우저 내부의 **`Web Worker` 로컬 엔진**이 모든 이미지 현상, 듀얼 브랜치 먼지 탐지, 평면 디트렌딩 인페인팅, DNG/TIFF/PNG/JPG/ZIP 생성을 직접 수행합니다.
  - `wrangler.toml`과 `public/_headers`를 포함해 `npm run build` 결과물(`dist/`)을 Cloudflare Pages에 바로 배포할 수 있습니다.
