# 다크룸 툴바 레이아웃 분리 (좌우 스크롤 제거) 및 확대 시 사진 상하좌우 이동 개선 계획

하단 단일 바에 모든 도구가 몰려 발생하던 좌우 스크롤을 완전히 없애기 위해 **좌측 세로 툴바(펜·이동 도구·크기·실행취소)**와 **하단 뷰 바(뷰 모드·오버레이·확대)**로 공간을 분리하고, 사진 확대 시 **마우스 휠(상하/좌우 스크롤)**, **스페이스바+드래그**, **손바닥(이동) 도구**를 통해 사진을 자유롭게 이동할 수 있도록 개선합니다.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 아래 확정된 설계 방향을 검토해 주시고 **Proceed**를 눌러주시면 즉시 코드에 반영하겠습니다.

- **Confirmed Decision 1 (툴바 레이아웃 분리 — 좌우 스크롤 완전 제거)**:
  - **좌측 세로 플로팅 툴바 (Left Vertical Dock)**: `스팟 추가 펜 (B)`, `스팟 제거 펜 (E)`, `손바닥 이동 도구 (H)`, 펜 반경 조절(`+`/`-` 및 세로/컴팩트 게이지), `되돌리기 (Undo)` / `다시 실행 (Redo)`를 캔버스 좌측에 세로로 깔끔하게 배치합니다.
  - **하단 뷰 & 줌 바 (Bottom View & Zoom Bar)**: `오버레이`, `#번호`, 뷰 모드(`복원본` · `분할` · `원본` · `엣지`), 확대/축소(`-` · `100%` · `+` · `화면 맞춤`)만 남겨 좌우 스크롤(`overflow-x`)이 절대 생기지 않도록 구성합니다.
- **Confirmed Decision 2 (확대 시 사진 상하·좌우 이동 방식)**:
  - **마우스 휠 이동**: 사진이 확대(`zoom > 100%`)된 상태에서 마우스 휠을 굴리면 사진이 **위·아래로 부드럽게 이동**하며, `Shift + 마우스 휠`(또는 트랙패드 2핑거 스크롤)로 좌·우 이동도 가능합니다 (`Ctrl/Cmd + 휠`은 줌 인/아웃).
  - **스페이스바(Space) + 드래그**: 펜 도구를 사용 중일 때도 `Space` 키를 누르고 있는 동안에는 손바닥 커서로 전환되어 마우스 드래그로 사진을 상하좌우 어디로든 이동할 수 있습니다.
  - **손바닥(이동) 도구 버튼 (`H`)**: 좌측 세로 툴바(및 모바일 도구 탭)에 **손바닥(이동) 도구** 버튼을 추가하여, 선택 시 드래그만으로 안전하게 확대된 사진을 상하좌우로 이동할 수 있습니다.

## 1. Overview & Core Concept

- **What It Does**:
  1. 캔버스 하단에 과밀하게 모여 있던 컨트롤들을 역할별로 **좌측 도구 독(편집·이동 도구)**과 **하단 뷰 독(비교·오버레이·줌)**으로 분리하여 한눈에 들어오는 쾌적한 다크룸 작업 환경을 제공합니다.
  2. 고배율(125%~400%) 확대 상태에서 센서 먼지를 정밀 검수할 때 마우스 휠, 스페이스바 드래그, 손바닥 도구로 사진의 상하좌우 끝까지 막힘없이 탐색할 수 있습니다.
- **Target Audience / Persona**: 라이트룸 입고 전 고해상도 RAW/TIFF 이미지의 센서 먼지를 100%~400% 확대하여 세밀하게 검수·제거하는 사진가.
- **Key Value**: 가로 스크롤바 조작의 불편함을 없애고, 확대 검수 시 사진 이동과 펜 작업 전환 속도를 극대화합니다.

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **도구 선택 및 펜 크기 조절 (좌측 세로 툴바)**:
     - 좌측 세로 툴바에서 `스팟 추가 펜`, `스팟 제거 펜`, `손바닥(이동)` 중 하나를 클릭하거나 단축키(`B`, `E`, `H`)로 즉시 전환합니다.
     - 같은 좌측 툴바에서 펜 반경(`+` / `-` 버튼 및 수치 표시)과 `Undo` / `Redo`를 바로 조작합니다.
  2. **확대 후 상하좌우 사진 탐색**:
     - 하단 바에서 `+` 버튼을 눌러 200% 이상 확대한 뒤, **마우스 휠**을 위아래로 굴려 사진을 상하로 이동하거나, **손바닥 도구(`H`)** 또는 **스페이스바+드래그**로 원하는 영역으로 자유롭게 이동합니다.
  3. **뷰 비교 및 오버레이 전환 (하단 바)**:
     - 좌우 스크롤 없이 한 줄에 정돈된 하단 바에서 `복원본` / `분할` / `원본` / `엣지` 뷰와 `오버레이` 표시 여부를 즉시 전환합니다.
- **Visual Identity & Theme**:
  - **60-30-10 다크룸 컬러 규율**: `#121212` 캔버스 배경(60%), `#3A3A3D` 및 `#2B2B2E` 툴바 표면과 `#535356` 헤어라인 보더(30%), `#556042` 올리브 액센트(10%)를 일관되게 유지합니다.
  - **Tabular Numerals**: 펜 반경(`28px`)과 줌 배율(`100%`)에 `tabular-nums`를 적용해 숫자 변화 시 레이아웃 흔들림을 방지합니다.

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: 좌측 세로 툴바 + 하단 뷰 바 분리 아키텍처**
  - *Chosen Approach*: 편집/조작 도구(`추가 펜`, `제거 펜`, `손바닥 이동`, `펜 크기`, `실행 취소/다시 실행`)는 캔버스 좌측 중앙(`left-3 top-1/2 -translate-y-1/2`) 세로 툴바로 분리하고, 시각 비교 및 배율 제어(`오버레이`, `#번호`, `뷰 모드`, `확대/축소`)만 하단 중앙(`bottom-3 left-1/2 -translate-x-1/2`)에 배치합니다.
  - *Why*: 라이트룸·포토샵·캡처원 등 전문 현상 소프트웨어의 표준 공간 배치와 일치하며, 일반적인 노트북/모니터 해상도에서도 하단 바의 가로 폭이 절반 이하로 줄어들어 가로 스크롤이 원천적으로 사라집니다.
- **Decision 2: 3중 이동(Panning) 입력 지원 및 팬 경계 보정**
  - *Chosen Approach*: ① `zoom > 1`일 때 마우스 휠 상하/좌우 이동(`Ctrl/Cmd + 휠`은 확대/축소), ② `Space` 키 홀드 중 드래그 이동, ③ `손바닥(이동)` 전용 도구를 동시에 지원합니다. 또한 `zoom === 1`로 복귀 시 팬 오프셋을 자동으로 중앙(`0, 0`)으로 정렬합니다.
  - *Why*: 트랙패드 사용자, 마우스 휠 사용자, 그래픽 타블렛/펜 사용자 모두에게 가장 익숙한 화면 이동 방식을 제공합니다.

### Interactive Component & State Mapping
- **`InteractionTool` 타입 확장**: `'pen-add' | 'pen-remove' | 'pan'`으로 확장하여 손바닥(이동) 도구를 정식 도구 상태로 관리합니다.
- **스페이스바 임시 패닝 (`isSpacePressed`)**: `keydown` / `keyup` 이벤트로 스페이스바 홀드 상태를 감지하여, 펜 도구가 선택된 상태에서도 스페이스바를 누르면 즉시 손바닥 커서(`cursor-grab`)로 바뀌며 드래그 시 스팟이 찍히지 않고 화면만 이동합니다.
- **마우스 휠 핸들러 (`handleWheel`)**:
  - `e.ctrlKey || e.metaKey`일 때는 줌 배율(`0.5x ~ 4.0x`)을 조절합니다.
  - 확대된 상태(`zoom > 1`)에서 일반 휠 입력 시 `pan.y -= e.deltaY`, `pan.x -= (e.shiftKey ? e.deltaY : e.deltaX)`로 상하·좌우 위치를 즉시 이동시킵니다.
